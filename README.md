# Protótipo TIM — GitHub Pages

Versão estática e responsiva do protótipo, pronta para publicação no GitHub Pages.

## Publicar pelo site do GitHub

1. Crie um repositório público no GitHub.
2. Abra **Add file → Upload files**.
3. Envie todos os arquivos desta pasta para a raiz do repositório.
4. Abra **Settings → Pages**.
5. Em **Source**, selecione **Deploy from a branch**.
6. Selecione a branch **main**, pasta **/(root)** e clique em **Save**.

O endereço será parecido com:

`https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`

## Estrutura

- `index.html`: conteúdo da página
- `styles.css`: visual responsivo
- `script.js`: carrossel, menu, modais e FAQ
- `.nojekyll`: impede processamento desnecessário pelo Jekyll

Não é necessário instalar Node.js, executar `npm install` ou gerar um build.
